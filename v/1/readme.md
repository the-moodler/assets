# ![moodler-32] Moodler Assets, version 1

**Released.** Browse it at ![moodler] <https://the-moodler.github.io/assets/v/1/>.

Version 1 only grows: new icons, files and folders can be added, but nothing in it is changed, renamed or deleted. A change or a delete goes in a new version, so a link into `v/1/` always shows the same picture.

Every icon is sorted into a category and named by its size.

## Categories

| Folder                                                                                      | What's in it                                                                                                                                                                                                                 | Icons |
|---------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------|
| ![folder] [`file-icons/`](https://github.com/the-moodler/assets/tree/master/v/1/file-icons) | File types (`pdf`, `docx`, `py` and so on), plus `folder`, `file` (no type of its own), `part` (part of a split archive) and `pdf-d` (the PDF download button). One folder per first letter, plus `numbers/` and `symbols/`. | 80    |
| ![folder] [`site-icons/`](https://github.com/the-moodler/assets/tree/master/v/1/site-icons) | The sites a link goes to: `github`, `moodle`, `sharepoint`, `teams`, `zoom`.                                                                                                                                                 | 5     |
| ![folder] [`link-icons/`](https://github.com/the-moodler/assets/tree/master/v/1/link-icons) | Links that aren't a file or a known site: `url`.                                                                                                                                                                             | 1     |
| ![folder] [`ui-icons/`](https://github.com/the-moodler/assets/tree/master/v/1/ui-icons)     | Places and buttons on a website: `pages`, `repo`, `search`, `settings`.                                                                                                                                                      | 4     |
| ![folder] [`symbols/`](https://github.com/the-moodler/assets/tree/master/v/1/symbols)       | Small signs for tables and text: `yes` (white tick on green), `no` (white cross on red).                                                                                                                                     | 2     |
| ![folder] [`branding/`](https://github.com/the-moodler/assets/tree/master/v/1/branding)     | Logos, one folder per app: ![folder] [`moodler/`](https://github.com/the-moodler/assets/tree/master/v/1/branding/moodler).                                                                                                   | 1     |

## File names and sizes

Every file is named by its height in pixels:

| File                                                                               | What it is                                                                                    |
|------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------|
| [`pdf-16.png`](https://the-moodler.github.io/assets/v/1/file-icons/p/pdf-16.png)   | 16 pixels tall. What readmes link: it sits in a line of GitHub text without making it taller. |
| [`pdf-16.svg`](https://the-moodler.github.io/assets/v/1/file-icons/p/pdf-16.svg)   | The same 16-pixel drawing as an SVG.                                                          |
| [`pdf-24.png`](https://the-moodler.github.io/assets/v/1/file-icons/p/pdf-24.png)   | The smooth drawing at 24 pixels.                                                              |
| [`pdf-24.svg`](https://the-moodler.github.io/assets/v/1/file-icons/p/pdf-24.svg)   | The smooth drawing as an SVG, which scales to any size.                                       |
| [`pdf-256.png`](https://the-moodler.github.io/assets/v/1/file-icons/p/pdf-256.png) | The smooth drawing at 256 pixels.                                                             |

An icon from elsewhere keeps its original too, at its real size: [`moodle-200.png`](https://the-moodler.github.io/assets/v/1/site-icons/moodle-200.png), [`sharepoint-1280.png`](https://the-moodler.github.io/assets/v/1/site-icons/sharepoint-1280.png), [`url-512.png`](https://the-moodler.github.io/assets/v/1/link-icons/url-512.png). A wide icon, like the `pdf-d` button, is named by its height. The logo is [`moodler-256.svg`](https://the-moodler.github.io/assets/v/1/branding/moodler/moodler-256.svg), plus [`moodler-16.png`](https://the-moodler.github.io/assets/v/1/branding/moodler/moodler-16.png) to [`moodler-512.png`](https://the-moodler.github.io/assets/v/1/branding/moodler/moodler-512.png). The `yes` and `no` signs only come at 16 pixels.

## Number and symbol folders

File icons are in one folder per first letter of their name, in lowercase, so the PDF icon is in ![folder] [`p/`](https://github.com/the-moodler/assets/tree/master/v/1/file-icons/p). A name that starts with a digit (`7z`) is in ![folder] [`numbers/`](https://github.com/the-moodler/assets/tree/master/v/1/file-icons/numbers). A name that starts with a symbol, such as an underscore, goes in `file-icons/symbols/`, which appears when it has an icon to hold. The dot before a file type isn't part of the icon's name, so an icon for `.gitignore` would be `gitignore`, in ![folder] [`g/`](https://github.com/the-moodler/assets/tree/master/v/1/file-icons/g).
